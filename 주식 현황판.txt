📄 PRD: 스마트 주식 통합 현황판 (Smart Stock Dashboard) v1.0

1. 문서 개요 (Document Overview)

  - 제품명: 스마트 주식 통합 현황판 (가칭 'StockBoard')
  - 버전: v1.0 (MVP)
  - 목표 플랫폼: PC 웹 기반 대시보드 (우선순위) 및 태블릿/모바일 반응형 웹
  - 핵심 가치: 투자자가 여러 앱을 켤 필요 없이, 국내외 주식부터 ETF, 실시간 뉴스, 심층 재무 데이터(100대 기업)까지 한 화면에서
    직관적으로 분석할 수 있는 '올인원(All-in-one) 투자 정보 환경' 제공

2. 제품 배경 및 목적 (Background & Objectives)

  - 배경: 현대의 개인 투자자들은 국내 주식뿐만 아니라 해외 주식, ETF 등 다양한 자산에 분산 투자하고 있으며, 차트 분석(기술적
    분석)과 재무제표 분석(기본적 분석)을 병행합니다. 하지만 이를 위해 HTS, 포털 금융, 공시 사이트(DART) 등을 번갈아
    확인해야 하는 불편함이 있습니다.
  - 목적:
    1.  흩어진 투자 정보(시세, 차트, 뉴스, 재무제표)를 단일 대시보드로 통합 제공.
    2.  주요 시장(국내/해외/ETF) 현황 및 장외 거래 동향을 한눈에 파악할 수 있는 시각화(Graph) 제공.
    3.  시가총액 상위 100대 기업의 재무제표를 즉시 조회할 수 있게 하여 투자 결정 시간 단축.

3. 사용자 페르소나 (User Personas)

  - 페르소나 1 (가치 투자자 / 30대 후반 직장인): "기업의 본질이 중요합니다. 차트는 연간/월간 등 장기 추세를 주로 보며,
    우량주(100대 기업) 위주로 매출액, 영업이익 등 재무제표를 꼼꼼히 확인하고 투자합니다."
  - 페르소나 2 (트렌드 투자자 / 20대 후반 전업/스윙 투자자): "시장 주도주와 ETF 흐름을 빨리 파악해야 합니다. 정규장 외의
    시간외/장외 거래 시세를 확인하고, 종목과 관련된 실시간 뉴스를 바탕으로 단기/주간 차트를 분석합니다."

5. 비기능 요구사항 (Non-Functional Requirements)

  - 성능 및 실시간성: 주식 시세 및 차트 데이터는 최소 지연(WebSocket 등 활용 또는 1분 단위 폴링)으로 업데이트되어야 하며,
    초기 로딩 시간은 2초 이내여야 함.
  - 가시성(UI/UX): 재무제표와 같이 숫자가 많은 데이터는 테이블 포맷에 가독성을 높이는 타이포그래피(천 단위 콤마, 상승/하락 색상
    구분 - 한국은 🔴상승/🔵하락, 해외는 🟢상승/🔴하락 등 설정 가능)를 적용.
  - 데이터 신뢰성: 모든 시세 및 재무 데이터는 공신력 있는 증권사 API 및 DART(전자공시) 데이터를 연동하여 제공해야 함.

6. 화면 구성 및 사용자 흐름 (UX/UI & View Structure)

6.1 주요 화면 (Views)

1.  메인 대시보드 (Main Board)
      - 좌측 패널: 국내/해외/ETF 카테고리 트리 및 내 관심기업(Watchlist) 리스트.
      - 중앙 상단: 주요 지수 및 관심종목 미니 그래프, 장외/시간외 거래 핫이슈 종목.
      - 중앙 하단: 시장 주요 실시간 뉴스 피드.
2.  종목 상세 화면 (Detail View)
      - 상단에 현재가 및 정규/장외 시세 정보.
      - 중앙에 대형 인터랙티브 차트 (일/주/월/연간 탭 전환).
      - 하단에 해당 종목 관련 뉴스 및 기업 정보.
3.  재무제표 센터 (Financials Top 100)
      - 시가총액 1~100위 기업 랭킹 보드.
      - 특정 기업 클릭 시 화면 분할을 통해 우측에 연간/분기별 요약 재무제표 및 투자 지표 테이블 노출.

7. 시스템 아키텍처 및 연동 API (System & API Strategy)

  - 프론트엔드 (Front-end):
      - React.js 또는 Vue.js (SPA 기반의 빠르고 매끄러운 화면 전환)
      - 차트 라이브러리: TradingView Lightweight Charts 또는 Highcharts (금융 데이터 시각화에 최적화)
  - 백엔드 (Back-end):
      - Spring Boot (Java) 또는 Node.js (실시간 데이터 파이프라인 처리에 적합)
      - DB: MySQL/PostgreSQL (회원 정보 및 관심종목 저장), Redis (실시간 시세 캐싱)
  - 외부 API 연동 (External APIs):
      - 시세/차트/장외거래: 한국투자증권 Open API (국내/해외 주식 및 시간외 시세), Yahoo Finance API
      - 재무제표: DART(금융감독원 전자공시시스템) Open API (국내 100대 기업 재무 데이터 자동 파싱)
      - 뉴스 피드: 네이버 검색 API (뉴스 부문), 또는 금융 특화 뉴스 RSS 연동

8. 마일스톤 및 개발 일정 (Milestones) - 8주(2개월) 스프린트 기준

  - Week 1-2 (기획/설계): PRD 확정, UI/UX 와이어프레임(Figma) 작성, API 연동 가능성(증권사, DART)
    PoC(개념 증명) 테스트.
  - Week 3-4 (기본 뼈대 구축): 프론트엔드 대시보드 레이아웃 개발, 카테고리(국내/해외/ETF) 분류 및
    관심기업(Watchlist) DB 설계.
  - Week 5-6 (핵심 기능 연동): 멀티 타임프레임(일/주/월/연) 차트 렌더링, 장시간/장외 시세 연동, 뉴스 피드 API 연동.
  - Week 7-8 (심화 기능 및 마무링): 상위 100대 기업 재무제표 데이터베이스화 및 뷰어 UI 연동, 통합 버그 수정(QA) 및
    베타 론칭.

9. 성공 지표 (Success Metrics, KPIs)

  - User Engagement: 방문자당 평균 체류 시간 (목표: 10분 이상 - 차트 및 재무 분석 시간).
  - Feature Usage: 전체 세션 중 '100대 기업 재무제표 탭' 조회 비율 (목표: 30% 이상).
  - Retention: 관심기업(Watchlist)에 5개 이상의 종목을 등록한 활성 사용자(Active User)의 재방문율.
