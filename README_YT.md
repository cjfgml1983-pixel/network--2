# 📺 유튜브 다운로더 사용 설명서

본 리포지토리에 포함된 `youtube_downloader.py`는 강력한 오픈소스 도구인 **yt-dlp**를 기반으로 제작되었습니다.

## 🛠 설치 방법
파이썬(Python)이 설치된 환경에서 아래 명령어를 입력하여 필요한 라이브러리를 먼저 설치해 주세요.

```bash
pip install -r requirements_yt.txt
```

## 🚀 실행 방법
터미널이나 명령 프롬프트(CMD)에서 아래 명령어를 입력하여 프로그램을 실행합니다.

```bash
python youtube_downloader.py
```

## ✨ 주요 기능
1. **고화질 영상 다운로드**: 가장 좋은 화질의 MP4 영상을 자동으로 찾아 다운로드합니다.
2. **MP3 오디오 추출**: 영상 없이 고음질 오디오만 MP3 파일로 저장합니다.
3. **자동 경로**: 다운로드된 파일은 PC의 **[다운로드(Downloads)]** 폴더에 자동으로 저장됩니다.

---
*주의: 개인 소장용으로만 사용하시기 바라며, 저작권이 있는 콘텐츠의 무단 배포는 금지됩니다.*
